HTML Document Structure

Every HTML page starts with a standard structure called the "boilerplate". This tells the browser what kind of document it is and how to render it.

HTML 
<!DOCTYPE html>                    <!-- Declares HTML5 document -->
<html lang="en">                   <!-- Root element + language -->
<head>                               <!-- Metadata container -->
    <meta charset="UTF-8">            <!-- Character encoding -->
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>My Website</title>          <!-- Browser tab title -->
</head>
<body>                               <!-- Visible content -->
    <h1>Hello, World!</h1>
    <p>Welcome to my website.</p>
</body>
</html>
🎯 Use Cases
  • Every single web page requires this structure
  • Landing pages, portfolios, blogs, e-commerce sites
  • Email templates (simplified version)
  • Web applications built with any framework
💡 Key Points

<!DOCTYPE html> is NOT a tag — it's a declaration that tells browsers to use HTML5 standards mode. Without it, browsers may render pages in "quirks mode".

🌍 Real-World Example: Business Landing Page
HTML 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Premium coffee delivered to your door">
    <title>BrewCraft Coffee | Fresh Roasted Daily</title>
    <link rel="icon" href="favicon.ico">
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>...</header>
    <main>...</main>
    <footer>...</footer>
    <script src="app.js"></script>
</body>
</html>

Meta Tags & SEO

Meta tags provide metadata about your HTML document. They're essential for SEO, social media sharing, and controlling browser behavior.

HTML 
<head>
    <!-- Essential Meta Tags -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Learn HTML from scratch">
    <meta name="keywords" content="HTML, tutorial, web development">
    <meta name="author" content="John Doe">

    <!-- Open Graph (Facebook/LinkedIn) -->
    <meta property="og:title" content="HTML Crash Course">
    <meta property="og:description" content="Complete HTML guide">
    <meta property="og:image" content="preview.jpg">
    <meta property="og:type" content="website">

    <!-- Twitter Card -->
    <meta name="twitter:card" content="summary_large_image">
    <meta name="twitter:title" content="HTML Crash Course">

    <!-- Favicon -->
    <link rel="icon" type="image/png" href="favicon.png">

    <title>My Page Title | Brand Name</title>
</head>
🎯 Use Cases
  • SEO optimization for Google rankings
  • Social media preview cards (Facebook, Twitter, LinkedIn)
  • Mobile responsive design with viewport meta
  • Browser tab icons with favicon
  • Character encoding for international content
  • Page caching & refresh control
⚠️ Important

The viewport meta tag is crucial for responsive design. Without it, mobile devices will render your page at desktop width and scale it down.

Headings & Paragraphs

HTML provides six levels of headings (h1-h6) for document hierarchy and paragraphs for body text. Proper heading structure is vital for SEO and accessibility.

HTML 
<!-- Heading Hierarchy (h1 = most important) -->
<h1>Main Page Title</h1>          <!-- Only ONE per page -->
<h2>Section Title</h2>
<h3>Sub-section Title</h3>
<h4>Sub-sub-section</h4>
<h5>Minor Heading</h5>
<h6>Smallest Heading</h6>

<!-- Paragraphs -->
<p>This is a paragraph. Browsers automatically add
spacing before and after paragraphs.</p>

<p>This is another paragraph with a
<br>line break inside it.</p>

<!-- Horizontal Rule (thematic break) -->
<hr>
🌍 Real-World Example: Blog Post Structure
HTML 
<article>
    <h1>Complete Guide to Indoor Plants</h1>
    <p>Indoor plants can transform your living space...</p>

    <h2>Choosing the Right Plant</h2>
    <p>Consider light conditions in your home...</p>

    <h3>Low Light Plants</h3>
    <p>Snake plants and pothos thrive in low light...</p>

    <h3>Bright Light Plants</h3>
    <p>Succulents and cacti need direct sunlight...</p>

    <h2>Watering Schedule</h2>
    <p>Overwatering is the #1 killer of houseplants...</p>
</article>
🚫 Common Mistakes

Don't skip heading levels (e.g., h1 → h3). Don't use headings just for styling — use CSS instead. Always have exactly one <h1> per page for SEO.

Text Formatting

HTML 
<!-- Semantic (meaningful) elements -->

<sup>Superscript</sup>              <!-- x² -->

<!-- Code & Preformatted -->
<code>console.log("hello")</code>   <!-- Inline code -->
<pre>Preformatted    text</pre>    <!-- Preserves whitespace -->
<kbd>Ctrl + C</kbd>                <!-- Keyboard input -->
<samp>Output text</samp>           <!-- Sample output -->
<var>x</var>                       <!-- Variable -->

<!-- Quotations -->
<blockquote cite="https://example.com">
    The only way to do great work is to love what you do.
</blockquote>
<q>Inline quotation</q>
<cite>Book Title</cite>

Links & Navigation

The anchor tag <a> is the backbone of the web, creating hyperlinks between pages, sections, files, and external resources.

HTML 
<!-- Basic Link -->
<a href="https://google.com">Visit Google</a>

<!-- Open in New Tab -->
<a href="https://google.com" target="_blank" rel="noopener noreferrer">
    Google (new tab)
</a>

<!-- Internal Page Link -->
<a href="about.html">About Us</a>
<a href="/products/shoes.html">Shoes</a>

<!-- Anchor / Jump Link -->
<a href="#contact">Jump to Contact</a>
<section id="contact">...</section>

<!-- Email Link -->
<a href="mailto:hello@example.com">Email Us</a>

<!-- Phone Link -->
<a href="tel:+1234567890">Call Us</a>

<!-- Download Link -->
<a href="resume.pdf" download>Download Resume</a>
🌍 Real-World Example: Website Navigation Bar
HTML 
<nav aria-label="Main navigation">
    <a href="/" class="logo">MyBrand</a>
    <ul>
        <li><a href="/">Home</a></li>
        <li><a href="/products">Products</a></li>
        <li><a href="/about">About</a></li>
        <li><a href="/contact">Contact</a></li>
        <li><a href="tel:+18005551234">📞 Call Now</a></li>
    </ul>
</nav>
✅ Best Practice

Always add rel="noopener noreferrer" to links with target="_blank" to prevent security vulnerabilities (reverse tabnapping).

Images & Figures

Images make the web visual. HTML provides multiple ways to display images responsively with proper semantics.

HTML 
<!-- Basic Image (self-closing tag) -->
<img src="photo.jpg"
     alt="A golden retriever playing in a park"
     width="600"
     height="400">

<!-- Figure with Caption -->
<figure>
    <img src="chart.png" alt="Q4 Sales growth chart">
    <figcaption>Figure 1: Q4 2024 Sales Performance</figcaption>
</figure>

<!-- Responsive Image with <picture> -->
<picture>
    <source media="(min-width: 1200px)" srcset="hero-large.webp">
    <source media="(min-width: 768px)" srcset="hero-medium.webp">
    <img src="hero-small.jpg" alt="Hero banner">
</picture>

<!-- Lazy Loading (performance) -->
<img src="photo.jpg" alt="Description" loading="lazy">
🎯 Use Cases
  • Product photos on e-commerce sites
  • Blog post featured images
  • Portfolio galleries and photo grids
  • Data visualization charts with captions
  • Responsive hero banners (different sizes per device)
  • Lazy-loaded image feeds for performance
🚫 Never Skip Alt Text!

The alt attribute is essential for accessibility (screen readers), SEO, and as fallback when images fail to load. Use descriptive, meaningful text.

Lists

Lists organize content into structured formats. HTML offers ordered, unordered, and description lists.

HTML 
<!-- Unordered List (bullet points) -->
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<!-- Ordered List (numbered) -->
<ol>
    <li>Preheat oven to 350°F</li>
    <li>Mix dry ingredients</li>
    <li>Add wet ingredients</li>
    <li>Bake for 25 minutes</li>
</ol>

<!-- Custom Start Number -->
<ol start="5" type="A">
    <li>Item E</li>
    <li>Item F</li>
</ol>

<!-- Nested List -->
<ul>
    <li>Frontend
        <ul>
            <li>React</li>
            <li>Vue</li>
        </ul>
    </li>
    <li>Backend
        <ul>
            <li>Node.js</li>
            <li>Python</li>
        </ul>
    </li>
</ul>

<!-- Description List (key-value pairs) -->
<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language — the structure of web pages.</dd>
    <dt>CSS</dt>
    <dd>Cascading Style Sheets — the presentation layer.</dd>
</dl>

Tables

Tables display data in rows and columns. Use them only for tabular data — never for page layout.

HTML 
<table>
    <caption>Monthly Sales Report</caption>
    <thead>
        <tr>
            <th>Month</th>
            <th>Revenue</th>
            <th>Expenses</th>
            <th>Profit</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>January</td>
            <td>$45,000</td>
            <td>$32,000</td>
            <td>$13,000</td>
        </tr>
        <tr>
            <td>February</td>
            <td>$52,000</td>
            <td>$35,000</td>
            <td>$17,000</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td>Total</td>
            <td>$97,000</td>
            <td>$67,000</td>
            <td>$30,000</td>
        </tr>
    </tfoot>
</table>

<!-- Spanning cells -->
<td colspan="2">Spans 2 columns</td>
<td rowspan="3">Spans 3 rows</td>
🎯 Use Cases
  • Financial reports and spreadsheets
  • Pricing comparison tables
  • Sports scores and statistics
  • Schedule/timetable displays
  • Product feature comparisons
  • Data dashboards
Element Purpose Required?
<table> Table container ✅ Yes
<thead> Header group Recommended
<tbody> Body group Recommended
<tfoot> Footer group (totals) Optional
<tr> Table row ✅ Yes
<th> Header cell (bold, centered) Recommended
<td> Data cell ✅ Yes
<caption> Table title/description Recommended

Forms — Basics

Forms collect user input. They're used everywhere — login pages, search bars, checkout processes, surveys, and more.

HTML 
<form action="/submit" method="POST">

    <!-- Text Input -->
    <label for="name">Full Name:</label>
    <input type="text" id="name" name="name"
           placeholder="John Doe" required>

    <!-- Email Input -->
    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>

    <!-- Password -->
    <label for="pass">Password:</label>
    <input type="password" id="pass" name="password"
           minlength="8" required>

    <!-- Number -->
    <input type="number" min="1" max="100" step="1">

    <!-- Date -->
    <input type="date" name="birthday">

    <!-- Color Picker -->
    <input type="color" value="#6c5ce7">

    <!-- Range Slider -->
    <input type="range" min="0" max="100" value="50">

    <!-- File Upload -->
    <input type="file" accept="image/*" multiple>

    <!-- Checkbox -->
    <label>
        <input type="checkbox" name="agree" required>
        I agree to Terms & Conditions
    </label>

    <!-- Radio Buttons -->
    <fieldset>
        <legend>Gender:</legend>
        <label><input type="radio" name="gender" value="male"> Male</label>
        <label><input type="radio" name="gender" value="female"> Female</label>
    </fieldset>

    <!-- Submit Button -->
    <button type="submit">Register</button>

</form>
🌍 Real-World Example: Login Form
HTML 
<form action="/api/login" method="POST" class="login-form">
    <h2>Welcome Back 👋</h2>

    <div class="form-group">
        <label for="login-email">Email Address</label>
        <input type="email" id="login-email"
               name="email" placeholder="you@example.com"
               autocomplete="email" required>
    </div>

    <div class="form-group">
        <label for="login-pass">Password</label>
        <input type="password" id="login-pass"
               name="password" minlength="8"
               autocomplete="current-password" required>
    </div>

    <label class="remember">
        <input type="checkbox" name="remember"> Remember me
    </label>

    <button type="submit">Sign In</button>
    <a href="/forgot-password">Forgot password?</a>
</form>
✅ Best Practice

Always pair <label> with <input> using the for/id connection. This improves accessibility and creates a larger click target.

Forms — Advanced

Advanced form elements include dropdowns, textareas, autocomplete lists, and HTML5 validation attributes.

HTML 
<!-- Select Dropdown -->
<label for="country">Country:</label>
<select id="country" name="country" required>
    <option value="" disabled selected>Choose a country</option>
    <optgroup label="North America">
        <option value="us">United States</option>
        <option value="ca">Canada</option>
    </optgroup>
    <optgroup label="Europe">
        <option value="uk">United Kingdom</option>
        <option value="de">Germany</option>
    </optgroup>
</select>

<!-- Textarea -->
<label for="message">Message:</label>
<textarea id="message" name="message"
          rows="5" cols="40"
          maxlength="500"
          placeholder="Type your message..."></textarea>

<!-- Datalist (Autocomplete) -->
<label for="browser">Browser:</label>
<input list="browsers" id="browser" name="browser">
<datalist id="browsers">
    <option value="Chrome">
    <option value="Firefox">
    <option value="Safari">
    <option value="Edge">
</datalist>

<!-- Progress & Meter -->
<progress value="75" max="100">75%</progress>
<meter value="0.7" min="0" max="1" low="0.3" high="0.8">70%</meter>

<!-- Output (calculated result) -->
<output name="result">60</output>

<!-- HTML5 Validation Attributes -->
<input type="text" required>                  <!-- Must fill -->
<input type="text" minlength="3" maxlength="20">  <!-- Length limits -->
<input type="text" pattern="[A-Za-z]{3,}">      <!-- Regex pattern -->
<input type="url" placeholder="https://...">   <!-- URL validation -->

Audio & Video

HTML5 native audio and video elements let you embed media directly without plugins like Flash.

HTML 
<!-- Video Player -->
<video controls width="640" height="360"
       poster="thumbnail.jpg"
       preload="metadata">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    <track src="captions.vtt" kind="subtitles"
           srclang="en" label="English" default>
    Your browser doesn't support video.
</video>

<!-- Autoplay Muted (allowed by browsers) -->
<video autoplay muted loop playsinline>
    <source src="background.mp4" type="video/mp4">
</video>

<!-- Audio Player -->
<audio controls>
    <source src="song.mp3" type="audio/mpeg">
    <source src="song.ogg" type="audio/ogg">
    Your browser doesn't support audio.
</audio>
🎯 Use Cases
  • Video tutorials and courses
  • Background hero videos on landing pages
  • Podcast audio players
  • Music streaming previews
  • Product demo videos
  • Video testimonials
Attribute Description
controls Shows play/pause, volume, timeline
autoplay Auto-starts (needs muted for video)
muted Starts muted
loop Repeats when finished
poster Thumbnail image before play
preload none / metadata / auto
playsinline Prevents fullscreen on iOS

Semantic HTML

Semantic elements clearly describe their meaning to both browsers and developers, improving accessibility, SEO, and code readability.

HTML 
<body>
    <!-- Site Header -->
    <header>
        <nav aria-label="Primary">
            <a href="/">Logo</a>
            <ul>
                <li><a href="/">Home</a></li>
                <li><a href="/blog">Blog</a></li>
            </ul>
        </nav>
    </header>

    <!-- Main Content -->
    <main>
        <!-- Article (self-contained) -->
        <article>
            <header>
                <h1>Blog Post Title</h1>
                <time datetime="2024-12-15">Dec 15, 2024</time>
            </header>

            <section>
                <h2>Introduction</h2>
                <p>Article content here...</p>
            </section>

            <section>
                <h2>Details</h2>
                <p>More content...</p>
                <figure>
                    <img src="chart.png" alt="Data chart">
                    <figcaption>Fig 1: Results</figcaption>
                </figure>
            </section>
        </article>

        <!-- Sidebar -->
        <aside>
            <h3>Related Posts</h3>
            <ul>...</ul>
        </aside>
    </main>

    <!-- Site Footer -->
    <footer>
        <p>© 2024 MyBrand. All rights reserved.</p>
        <address>
            Contact: <a href="mailto:hi@example.com">hi@example.com</a>
        </address>
    </footer>
</body>
<header>
Intro content / navigation
<nav>
Navigation links
<main>
Main unique content
<article>
Self-contained content
<section>
Thematic grouping
<aside>
Sidebar / tangential
<footer>
Footer / closing info
<figure>
Self-contained media
<time>
Date / time value
<address>
Contact information
<details>
Collapsible content
<summary>
Details toggle label
💡 Why Semantic HTML Matters

SEO: Search engines better understand your content. Accessibility: Screen readers can navigate by landmarks. Maintainability: Code is more readable and organized.

HTML

    <div class="card-header">
        <h3>Product Name</h3>
    </div>
    <div class="card-body">
        <p>Description here...</p>
    </div>
    <div class="card-footer">

    </div>
</div>

<!-- <span> = Inline container -->
<p>
    Your order total is 
    <span class="price">$49.99</span>
     including 
    <span class="highlight">free shipping</span>.
</p>

<!-- Layout wrapper -->
<div class="container">
    <div class="row">
        <div class="col-6">Left Column</div>
        <div class="col-6">Right Column</div>
    </div>
</div>
Feature <div> <span>
Display Type Block-level Inline
Starts New Line? ✅ Yes ❌ No
Width Full width Content width
Common Use Layout sections Styling text parts
Semantic? ❌ No meaning ❌ No meaning

iFrame & Embed

iFrames embed external content like maps, videos, and other websites directly into your page.

HTML 
<!-- Embed YouTube Video -->
<iframe
    width="560"
    height="315"
    src="https://www.youtube.com/embed/dQw4w9WgXcQ"
    title="YouTube video player"
    frameborder="0"
    allow="accelerometer; autoplay; encrypted-media"
    allowfullscreen
    loading="lazy">
</iframe>

<!-- Embed Google Map -->
<iframe
    src="https://maps.google.com/maps?q=NYC&output=embed"
    width="600"
    height="450"
    style="border:0"
    allowfullscreen
    loading="lazy"
    title="Google Map">
</iframe>

<!-- Security: Sandbox attribute -->
<iframe
    src="https://external-site.com"
    sandbox="allow-scripts allow-same-origin"
    title="External content">
</iframe>
🎯 Use Cases
  • YouTube / Vimeo video embeds
  • Google Maps on contact pages
  • Spotify / SoundCloud music players
  • Social media post embeds
  • Code editors (CodePen, JSFiddle)
  • Payment forms (Stripe, PayPal)
⚠️ Security Warning

Always use the sandbox attribute for iFrames loading untrusted content. Never embed unknown URLs without restrictions.

Accessibility & Best Practices

Writing accessible HTML ensures your website can be used by everyone, including people using screen readers, keyboard navigation, and assistive technologies.

HTML 
<!-- 1. Always use alt text for images -->
<img src="logo.png" alt="Acme Corp logo">
<img src="divider.png" alt="" role="presentation">  <!-- decorative -->

<!-- 2. Label all form inputs -->
<label for="search">Search:</label>
<input type="search" id="search" aria-label="Search site">

<!-- 3. ARIA landmarks & roles -->
<nav aria-label="Main navigation">...</nav>
<main role="main">...</main>
<button aria-expanded="false" aria-controls="menu">☰</button>

<!-- 4. Skip navigation link -->
<a href="#main-content" class="skip-link">
    Skip to main content
</a>

<!-- 5. Use semantic elements -->
<button>Click me</button>           <!-- ✅ Good -->
<div onclick="click()">Click me</div>  <!-- ❌ Bad -->

<!-- 6. Language attribute -->
<html lang="en">
<p lang="es">Hola, mundo!</p>

<!-- 7. Collapsible content -->
<details>
    <summary>Frequently Asked Questions</summary>
    <p>Answer to the question goes here...</p>
</details>
✅ Accessibility Checklist

✔ All images have meaningful alt text
✔ All form inputs have labels
✔ Page has logical heading hierarchy (h1 → h2 → h3)
✔ Color is not the only way to convey info
✔ Interactive elements are keyboard-accessible
✔ Page language is declared with lang
✔ Use semantic HTML over div/span when possible
