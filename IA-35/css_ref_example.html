🧠 The scoring system

Specificity is like a 3-digit score: A - B - C

A = number of ID selectors
B = number of class selectors
C = number of element selectors

/* Compare like numbers */ 0-0-1 vs 0-1-0 → 0-1-0 WINS 0-1-0 vs 1-0-0 → 1-0-0 WINS

🧩 Simple example

/* Rule 1: element selector */ p { color: blue; } /* Rule 2: class selector */ .greeting { color: green; } /* Rule 3: id selector */ #special { color: red; } /* HTML */ <p id="special" class="greeting">What color am I?</p>
✅ Answer: RED. #special has score 1-0-0 and beats .greeting (0-1-0).

📜 Golden rules

1️⃣

Use classes for styling. They are flexible and usually low specificity.

2️⃣

Avoid IDs for styling. Use IDs for anchors and JavaScript hooks.

3️⃣

Do not use inline styles unless absolutely necessary.

4️⃣

Never overuse !important. It can cause a maintenance nightmare.

5️⃣

Equal specificity: the last rule wins.
