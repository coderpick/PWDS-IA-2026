1.2 Selectors — Targeting Elements

All selector types: basic, combinator, pseudo-class, pseudo-element, attribute

All Selector Types 
/* === BASIC SELECTORS === */
* { margin: 0; }                      /* Universal */
p { color: #333; }                    /* Element */
.card { padding: 20px; }              /* Class */
#hero { height: 100vh; }              /* ID */

/* === COMBINATOR SELECTORS === */
div p { }               /* Descendant (any p inside div) */
div > p { }              /* Direct child only */
h2 + p { }               /* Adjacent sibling */
h2 ~ p { }               /* General sibling */

/* === PSEUDO-CLASS SELECTORS === */
a:hover { color: red; }
a:active { color: blue; }
input:focus { outline: 3px solid blue; }
li:first-child { font-weight: bold; }
li:last-child { color: gray; }
li:nth-child(2n) { background: #f0f0f0; }    /* Even items */
li:nth-child(odd) { background: #fff; }     /* Odd items */
p:not(.special) { opacity: 0.7; }

/* === PSEUDO-ELEMENT SELECTORS === */
p::first-line { font-weight: bold; }
p::first-letter { font-size: 2em; }
.item::before { content: '→ '; }
.item::after { content: ' ✓'; }
input::placeholder { color: #aaa; }

/* === ATTRIBUTE SELECTORS === */
[type="text"] { border: 1px solid #ccc; }
a[href^="https"] { }       /* Starts with */
img[src$=".png"] { }       /* Ends with */
[class*="btn"] { }         /* Contains */

1.3 The Box Model

Content, padding, border, margin & box-sizing

Box Model Properties 
/* Always use border-box! */
* {
    box-sizing: border-box;
}

.card {
    /* Content dimensions */
    width: 300px;
    height: auto;

    /* Padding: space INSIDE the border */
    padding: 20px;                 /* All sides */
    padding: 10px 20px;             /* top/bottom  left/right */
    padding: 10px 20px 15px 25px;   /* top right bottom left */

    /* Border */
    border: 2px solid #6c5ce7;

    /* Margin: space OUTSIDE the border */
    margin: 20px auto;             /* Center horizontally */
}

/* box-sizing comparison */
.content-box { box-sizing: content-box; }  /* width = content only (default) */
.border-box { box-sizing: border-box; }    /* width = content + padding + border */

1.6 CSS Units

px, %, em, rem, vw, vh, vmin, vmax, ch, fr

Unit Type Relative To Use Case
px Absolute Screen pixel Borders, shadows, small details
% Relative Parent element Widths, responsive layouts
em Relative Parent font-size Padding/margin relative to font
rem Relative Root (<html>) font-size Font sizes, spacing (recommended)
vw Viewport 1% viewport width Full-width sections, fluid text
vh Viewport 1% viewport height Hero sections, full-screen layouts
vmin Viewport Smaller of vw/vh Responsive squares
ch Relative Width of "0" character Optimal reading width (60-80ch)
fr Fraction Grid available space CSS Grid columns/rows

2.1 Display Property

block, inline, inline-block, none, visibility

Display Values 
/* Block: takes full width, starts new line */
.block { display: block; }    /* div, p, h1-h6, section */

/* Inline: only takes needed width, no width/height */
.inline { display: inline; }   /* span, a, strong, em */

/* Inline-block: inline flow + accepts width/height */
.ib { display: inline-block; width: 150px; height: 80px; }

/* None: removes from flow completely */
.hidden { display: none; }

/* Visibility hidden: hidden but still takes space */
.invisible { visibility: hidden; }

2.2 Position Property

static, relative, absolute, fixed, sticky + z-index

Position Values 
/* Static (default): normal document flow */
.static { position: static; }

/* Relative: offset from normal position, still in flow */
.relative { position: relative; top: 10px; left: 20px; }

/* Absolute: removed from flow, positioned to nearest positioned ancestor */
.parent { position: relative; }  /* anchor */
.absolute { position: absolute; top: 0; right: 0; }

/* Fixed: positioned relative to viewport, stays on scroll */
.fixed { position: fixed; top: 0; left: 0; width: 100%; }

/* Sticky: toggles between relative and fixed */
.sticky { position: sticky; top: 0; }

/* Z-index: stacking order (only works on positioned elements) */
.front { z-index: 10; }
.back { z-index: 1; }

2.3 Flexbox — 1D Layout

flex-direction, justify-content, align-items, flex-grow/shrink, order, gap, wrapping

Flexbox Complete Guide 
/* === CONTAINER (Parent) Properties === */
.container {
    display: flex;
    flex-direction: row;          /* row | row-reverse | column | column-reverse */
    justify-content: center;      /* flex-start | center | flex-end | space-between | space-around | space-evenly */
    align-items: center;          /* flex-start | center | flex-end | stretch | baseline */
    flex-wrap: wrap;              /* nowrap | wrap | wrap-reverse */
    gap: 20px;                     /* space between items */
    align-content: center;        /* for multi-line flex containers */
}

/* === ITEM (Child) Properties === */
.item {
    flex-grow: 1;       /* how much to grow (0 = don't grow) */
    flex-shrink: 0;     /* how much to shrink (0 = don't shrink) */
    flex-basis: 200px;  /* initial size before growing/shrinking */
    flex: 1 0 200px;    /* shorthand: grow shrink basis */
    order: 2;            /* change visual order */
    align-self: flex-end; /* override align-items for this item */
}

2.4 CSS Grid — 2D Layout

grid-template, fr units, span, areas, auto-fit/minmax, gap

CSS Grid Complete Guide 
/* === CONTAINER Properties === */
.grid {
    display: grid;
    grid-template-columns: 200px 1fr 1fr;        /* fixed + flexible */
    grid-template-columns: repeat(3, 1fr);        /* 3 equal columns */
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); /* responsive! */
    grid-template-rows: auto 1fr auto;
    gap: 20px;
}

/* === Grid Areas (named layout) === */
.grid {
    grid-template-areas:
        "header header header"
        "sidebar main   main"
        "footer footer footer";
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }

/* === ITEM Properties === */
.item {
    grid-column: span 2;        /* spans 2 columns */
    grid-column: 1 / 3;         /* from line 1 to 3 */
    grid-column: 1 / -1;        /* full width */
    grid-row: span 2;           /* spans 2 rows */
}

3.5 CSS Animations & @keyframes

@keyframes, animation properties, iteration, direction, fill-mode, real loaders

Animation Syntax 
/* Define keyframes */
@keyframes bounce {
    0%, 100% { transform: translateY(0); }
    50%      { transform: translateY(-30px); }
}

@keyframes fadeIn {
    from { opacity: 0; transform: translateY(20px); }
    to   { opacity: 1; transform: translateY(0); }
}

/* Apply animation */
.element {
    animation-name: bounce;
    animation-duration: 1s;
    animation-timing-function: ease;
    animation-delay: 0s;
    animation-iteration-count: infinite;  /* number | infinite */
    animation-direction: alternate;      /* normal | reverse | alternate */
    animation-fill-mode: forwards;       /* none | forwards | backwards | both */

    /* Shorthand */
    animation: bounce 1s ease infinite;
}

4.1 Responsive Design & Media Queries

Viewport meta, breakpoints, mobile-first approach, responsive patterns

Media Queries & Responsive Design 
<!-- Always include viewport meta tag -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

/* === Mobile-First Approach (recommended) === */

/* Base styles for mobile (no media query) */
.grid {
    display: grid;
    grid-template-columns: 1fr;  /* single column on mobile */
    gap: 20px;
}

/* Tablet (≥ 576px) */
@media (min-width: 576px) {
    .grid { grid-template-columns: repeat(2, 1fr); }
}

/* Laptop (≥ 768px) */
@media (min-width: 768px) {
    .grid { grid-template-columns: repeat(3, 1fr); }
}

/* Desktop (≥ 1024px) */
@media (min-width: 1024px) {
    .grid { grid-template-columns: repeat(4, 1fr); }
}

/* === Common Breakpoints === */
/* 480px  — Small phones */
/* 576px  — Large phones */
/* 768px  — Tablets */
/* 992px  — Small laptops */
/* 1200px — Desktops */
/* 1400px — Large screens */

/* Other media features */
@media (prefers-color-scheme: dark) { /* dark mode */ }
@media (orientation: landscape) { /* landscape */ }

4.2 CSS Custom Properties (Variables)

Defining, using, scoping, and theming with CSS variables

CSS Variables 
/* Define global variables on :root */
:root {
    --primary: #6c5ce7;
    --secondary: #00cec9;
    --font-size-base: 16px;
    --spacing: 20px;
    --radius: 12px;
    --shadow: 0 10px 30px rgba(0,0,0,0.1);

.card {
    background: var(--primary);
    padding: var(--spacing);
    border-radius: var(--radius);
    box-shadow: var(--shadow);
    transition: var(--transition);
}

/* Fallback value */
color: var(--undefined-var, #333);

/* Scoped variables (local override) */
.dark-section {
    --primary: #a29bfe;  /* overrides for children */
}

/* Dark mode theming */
@media (prefers-color-scheme: dark) {
    :root {
        --primary: #a29bfe;
        --bg: #1e1e1e;
        --text: #f0f0f0;
    }

4.5 Modern CSS Features

clamp(), aspect-ratio, scroll-snap, :is(), :where(), :has(), container queries

Modern CSS (2023+) 
/* clamp() — responsive values without media queries */
font-size: clamp(1rem, 3vw, 2.5rem);  /* min, preferred, max */
width: clamp(300px, 50%, 800px);
padding: clamp(10px, 3vw, 40px);

/* aspect-ratio */
.video { aspect-ratio: 16 / 9; }
.square { aspect-ratio: 1 / 1; }

/* Scroll Snap */
.container {
    scroll-snap-type: x mandatory;
    overflow-x: auto;
}
.item { scroll-snap-align: start; }

/* :is() — reduces repetition */
:is(h1, h2, h3) { font-weight: 700; }
.card :is(h2, h3, p) { margin-bottom: 10px; }

/* :has() — parent selector (game changer!) */
.card:has(img) { padding-top: 0; }
form:has(:invalid) { border-color: red; }

/* Custom scrollbar */
::-webkit-scrollbar { width: 8px; }
::-webkit-scrollbar-thumb { background: #6c5ce7; border-radius: 10px; }

/* accent-color (form controls) */
input[type="checkbox"] { accent-color: #6c5ce7; }
